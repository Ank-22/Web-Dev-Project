## Project Title: Food Recipe & Social Media Platform

This project is a web application dedicated to culinary enthusiasts, combining features of a recipe website and a social media platform. It allows users to discover recipes, engage with others, and receive curated restaurant recommendations tailored to diverse dining experiences. Whether you’re looking for a quick meal suggestion or embarking on a culinary journey, this site aims to enhance your food discovery and sharing experience.

### Key Features
- **Recipe Search and Discovery**: Users can explore a variety of recipes with tailored recommendations based on unique themes like hidden gems, global cuisines, or regional delicacies.
- **Social Interaction**: Users can form groups, share recipes, comment, and like each other’s posts, creating a community centered around food.
- **Cruise-based Restaurant Recommendations**: A unique feature where users receive restaurant recommendations based on specific cruise experiences.
- **Student Mode**: A dedicated section for students, offering budget-friendly meal options and convenient recipes ideal for busy schedules.

### UI Concept
The UI is designed to provide a unique, book-style interface with smooth scroll effects, integrating a **parallax effect** for immersive navigation:
- **Recipe Presentation**: Each recipe is displayed in a unique “page” format, where users can scroll through recipes as if flipping through a cookbook.
- **User Interactions**: Commenting on a recipe triggers an overlay resembling a piece of paper, bringing up all interactions associated with the recipe.
